# K-Town Defence 데모 로그인·브랜드 전환·지도 선택 UX 설계

## 배경

현재 데모는 별도의 로그인 과정 없이 아티스트 선택 또는 서비스 화면으로 바로 진입한다. 서비스 정체성을 처음 방문한 사용자에게 각인할 진입 경험이 없고, 지도에서는 선택한 지역의 채움이 약해 경계만 보이는 것처럼 느껴진다. 또한 데스크톱 지도 카메라가 오른쪽에 과도한 여백을 두어 선택 지역을 화면 왼쪽으로 밀어낸다. 거점 단계별 테두리 색상도 팬덤 식별을 방해한다.

## 목표

- 서버 없이 작동하는 간단한 데모 로그인을 제공한다.
- 로그인 직후 `K-TOWN DEFENCE` 브랜드를 강조하는 짧은 전환 화면을 보여준다.
- 선택 지역 전체를 팬덤 색의 옅은 반투명 채움으로 명확히 표시한다.
- 선택한 지역 경계 전체가 지도 화면 중앙에 오도록 카메라를 이동한다.
- 거점 테두리를 단계가 아닌 팬덤 고유 색상으로 통일한다.

## 범위 밖

- 실제 회원 가입, 계정 저장, OAuth 또는 서버 인증
- 비밀번호 복구와 이메일 인증
- 로그아웃 및 계정 관리 기능
- 거점 단계·보상·버프 규칙 변경
- 지도 데이터 또는 행정 경계 자체의 변경

## 진입 상태와 데이터

앱 진입 상태는 기존 팬덤 데모 세션과 분리된 세 단계 상태 머신으로 관리한다.

1. `login`: 로그인 폼 표시
2. `brand-transition`: 브랜드 전환 화면 표시
3. `service`: 기존 K-Town Defence 서비스 표시

데모 로그인 완료 여부는 별도 키로 `sessionStorage`에 저장한다. 같은 탭에서 새로고침하면 로그인과 브랜드 전환을 반복하지 않고 서비스로 바로 돌아간다. 새 탭이나 새 브라우저 세션에서는 다시 로그인한다. 기존 팬덤·영토 상태는 현재의 `localStorage` 저장 규칙을 그대로 사용한다.

로그인 폼은 유효한 이메일 형식과 비어 있지 않은 비밀번호만 검사한다. 실제 자격 증명 확인은 하지 않으며, 화면에 데모 로그인임을 명확히 알린다. 실패 시 입력값을 지우지 않고 해당 필드와 연결된 오류 문구를 제공한다.

## 로그인 화면

로그인 화면은 전체 화면의 짙은 브랜드 그린 배경과 중앙 카드로 구성한다.

- 카드 상단: 라임색 `K` 심볼과 흰색 `K-TOWN DEFENCE` 워드마크
- 본문: 이메일 및 비밀번호 입력, 로그인 버튼
- 안내: 임의의 이메일과 비밀번호로 체험할 수 있다는 설명
- 접근성: 명시적 라벨, 오류 설명 연결, 키보드 제출, 명확한 포커스 표시
- 반응형: 모바일에서도 가로 스크롤 없이 한 화면 안에 주요 입력과 버튼이 보이도록 구성

## 브랜드 전환 화면

로그인 성공 직후 카드 없는 전체 화면 전환을 표시한다.

- 짙은 브랜드 그린 배경
- 중앙의 라임 `K` 심볼과 큰 흰색 `K-TOWN DEFENCE` 워드마크
- 약 1.5초 동안 짧은 페이드와 스케일 애니메이션
- 화면 클릭 또는 Enter·Space 입력 시 즉시 서비스로 이동
- 하단에 “클릭하여 바로 시작” 안내
- `prefers-reduced-motion` 사용자는 움직임 없이 정적 브랜드 화면을 거쳐 자동 전환
- 타이머와 이벤트 리스너는 화면 종료 시 정리하여 중복 전환을 막음

## 지도 선택 표시

선택 지역은 기존 행정 경계 GeoJSON을 그대로 사용한다.

레이어 순서는 다음과 같이 고정한다.

1. 일반 영토 채움
2. 선택 지역 채움
3. 일반 영토 경계
4. 선택 지역 경계
5. 원정선·관광 포인트·거점 마커

선택 지역 채움은 해당 지역의 `ownerColor`를 사용하고 불투명도는 `0.38`로 설정한다. 이를 통해 도로와 지명은 유지하면서 선택 영역 전체를 명확히 구분한다. 선택 지역 경계선은 기존의 진한 외곽선을 유지한다.

선택이 변경되면 해당 폴리곤 경계를 `fitBounds`로 맞춘다. 데스크톱은 상하좌우 `56px`, 모바일은 상하좌우 `32px`의 대칭 여백을 사용한다. 최대 줌은 `9`로 유지하여 작은 지역도 과도하게 확대되지 않으면서 화면 중앙에 오게 한다. 행정 경계가 없을 때만 기존 중심 좌표 기반 이동을 사용한다. 모션 감소 설정에서는 즉시 이동한다.

## 거점 마커

거점 원의 채움과 테두리 모두 `ownerColor`를 사용한다. 씨앗·나무·랜드마크의 테두리 색과 굵기 차이는 제거하고 모든 단계에 같은 테두리 굵기를 적용한다.

단계 구분은 다음 요소로 유지한다.

- 거점 원 크기: 씨앗 < 나무 < 랜드마크
- 중앙 아티스트 로고 크기: 씨앗 < 나무 < 랜드마크
- 상세 패널의 단계 이름과 버프 설명

## 오류 및 복구

- 저장소 접근이 불가능하면 현재 탭의 메모리 상태만 사용하여 로그인 흐름을 계속한다.
- 로그인 입력 오류는 폼 안에서 설명하고 서비스 오류 화면으로 전환하지 않는다.
- 지도 경계 데이터가 없으면 기존 중심 좌표 카메라 이동으로 대체한다.
- 지도 로딩 실패 처리와 재시도 UI는 기존 동작을 유지한다.

## 테스트 전략

### 자동 테스트

- 로그인: 이메일 형식, 빈 비밀번호, 성공 제출, 키보드 제출
- 세션: 성공 상태의 `sessionStorage` 저장 및 새로고침 시 로그인 생략
- 전환 화면: 1.5초 자동 이동, 클릭·Enter·Space 건너뛰기, 타이머 정리, 모션 감소 처리
- 지도 채움: 선택 레이어가 `ownerColor`, 불투명도 `0.38`을 사용하고 올바른 레이어 순서를 가짐
- 지도 카메라: 데스크톱 `56px`, 모바일 `32px` 대칭 여백과 최대 줌 `9`
- 거점 마커: 모든 단계가 `ownerColor` 테두리와 동일 굵기를 사용하면서 단계별 반지름을 유지
- 회귀: 기존 팬덤 선택, 원정, 체크인, 내 기록 흐름

### 브라우저 QA

- 데스크톱과 모바일 크기에서 로그인 폼이 잘리지 않는지 확인
- 로그인 후 브랜드 화면이 자동 및 수동으로 정상 종료되는지 확인
- 군포를 선택했을 때 경계 내부 전체가 옅은 팬덤 색으로 채워지는지 확인
- 군포 경계가 지도 화면 중앙에 배치되는지 확인
- 씨앗·나무·랜드마크 거점 테두리가 각 소유 팬덤 색으로 일관되는지 확인
- 콘솔 오류와 프레임워크 오류 오버레이가 없는지 확인

## 수용 기준

- 사용자는 임의의 유효한 이메일과 비어 있지 않은 비밀번호로 데모에 로그인할 수 있다.
- 로그인 성공 후 `K-TOWN DEFENCE` 전체 화면 브랜드 전환이 최대 1.5초 표시된다.
- 사용자는 클릭 또는 Enter·Space로 브랜드 전환을 즉시 건너뛸 수 있다.
- 같은 탭을 새로고침해도 로그인과 브랜드 전환이 반복되지 않는다.
- 군포를 포함한 선택 지역은 경계 내부 전체가 소유 팬덤 색의 반투명 채움으로 표시된다.
- 선택 지역은 데스크톱과 모바일 모두 지도 화면 중앙에 배치된다.
- 모든 거점 테두리는 단계와 관계없이 소유 팬덤 고유 색을 사용한다.
- 기존 단계별 크기, 로고, 버프, 팬덤·원정·기록 기능은 유지된다.
